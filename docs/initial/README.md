# Source documents (kept private)

The project started from two internal documents: a technical blueprint for HK Cantonese speech
models and a task brief for the implementation agent. They include internal product plans and
details that are not meant for publication, so they are **not in this public repo**.

- Maintainers keep them locally in `private/initial/` (git-ignored). Ask a maintainer for a copy.
- Everything the project needs from them is carried into the living docs: data cards (`data/sources/`),
  pipelines (`data/pipelines/`), recipes (`recipes/`), base-model cards, the roadmap and the decision records.
- Where a living doc says "blueprint", it means that internal document. Any figure that came from it, and was
  not reproduced here, is labelled as such.

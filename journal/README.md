# Journal (lab notebook)

Dated, informal, append-only notes: `YYYY-MM-DD-<slug>.md`. Use it for whatever does not fit an
experiment card or a decision record: observations, hunches, dead ends, things heard in samples, links,
questions for the team. Do not rewrite old entries. Add a new entry that refers back to them.

Each entry has a few lines at the top:

```markdown
# YYYY-MM-DD: <title>
Author: <human or agent> · Related: E####, ADR NNNN
```
